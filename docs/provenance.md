# Provenance

## Baseline, 2026-11-03

SalesDesk starts in an empty standalone repository. The initial contribution comprises
new project documentation, a React/Vite bootstrap page, a FastAPI health endpoint,
dependency locks and CI/repository checks. It contains no working agent or sandbox.
Code and documentation were authored with AI assistance in collaboration with the owner.

Earlier brainstorming developed the research → execute demonstration → prepare outreach
concept. No code or data from existing commercial products was imported. Future changes
are recorded by Git commits, with observed implementation status in STATUS.md.

External dependency code is installed from package registries, not copied into the
source tree. See THIRD_PARTY.md. Disclose any future reused code and its permissions.


## Dealer-group surface, 2026-11-06

Original hackathon additions: seeded fictional dealer-group generator and CSVs, bounded
CSV imports, deterministic rooftop matching/risk program and independent reconciliation,
parallel fan-out atop the existing leased job engine, two Vultr inference contracts,
version-bound manager follow-ups and CRM/transfer exports, recurring Mountain Time
schedules, regional group/store UI and direct browser acceptance.

The earlier SalesDesk sandbox, provider transport, budgets, accepted replay and session
boundaries were reused. Prior campaign/prospect routes remain unlinked. No private
repository, customer dataset, live CRM/DMS or copied vendor application code was imported.
Vehicles use real product names; people, stores and VINs are fictional. Inline SVG visuals
are original code. Public screenshots show actual execution on the synthetic sample.
External industry evidence is linked in slides and THIRD_PARTY.md; no vendor graphics are
bundled. Narrated video, PDF export and official submission remain owner actions.
