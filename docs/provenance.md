# Provenance

## Baseline, 2026-11-03

ProofDesk starts in an empty standalone repository. The initial contribution comprises
new project documentation, a React/Vite bootstrap page, a FastAPI health endpoint,
dependency locks and CI/repository checks. It contains no working agent or sandbox.
Code and documentation were authored with AI assistance in collaboration with the owner.

Earlier brainstorming developed the research → execute demonstration → prepare outreach
concept. No code or data from existing commercial products was imported. Future changes
are recorded by Git commits, with observed implementation status in STATUS.md.

External dependency code is installed from package registries, not copied into the
source tree. See THIRD_PARTY.md. Disclose any future reused code and its permissions.
